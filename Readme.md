## 📌 About The Project

This is a personal **Graphic Design Portfolio Website** created to showcase creative work, design skills, tools, and professional information in a clean and modern interface.

The portfolio focuses on presenting design projects through an interactive gallery while providing visitors with an easy way to explore skills and get in touch.

The website features a dark, modern aesthetic with a pink accent color, smooth animations, responsive layouts, and interactive image previews.

## 🎯 Design Preview Interaction

The portfolio gallery uses an interactive hover experience.

```text
┌───────────────┐
│   Thumbnail   │
└───────┬───────┘
        │
      HOVER
        ↓
┌─────────────────────────┐
│                         │
│      FULLSCREEN         │
│         IMAGE           │
│                         │
└─────────────────────────┘
        │
   MOUSE LEAVES
        ↓
   Smooth Minimize
        ↓
┌───────────────┐
│   Thumbnail   │
└───────────────┘
```

This provides a more interactive experience than a traditional click-based image gallery.

## 🌐 Deployment

This project can be easily deployed using **GitHub Pages**.

### Steps

1. Push the project to GitHub.
2. Open the repository.
3. Go to **Settings**.
4. Select **Pages**.
5. Under **Build and deployment**, select:

   * Source: `Deploy from a branch`
   * Branch: `main`
   * Folder: `/ (root)`
6. Save the configuration.

Your portfolio will then be available through GitHub Pages.
